Privacy Policy

Last Updated: August 13, 2026
Summary: SteamValue values your privacy. We do not sell, track, or share your personal information. Your profile preferences, wishlist data, and library information are stored locally on your device.

1. Information We Process

SteamValue processes minimal data required to provide game deal lookup and recommendation services:

  • Steam Profile URLs: When you provide a public Steam profile link, we resolve your public Steam ID to fetch your public game library list and playtime data.
  • Wishlist & Preferences: Your tracked wishlist items, selected currency (INR, USD, EUR), and layout choices are stored locally using Chrome's chrome.storage API.
  • Custom Text Libraries: Games pasted into the Smart Text Importer are processed solely to search for matching title images and filter owned deals.

2. How We Use Data

Data processed by SteamValue is used strictly to:

  • Calculate discount Buy-Scores comparing current prices to historical lows.
  • Hide owned games from deal suggestions when the setting is enabled.
  • Generate game recommendations based on your played titles.

3. Third-Party Services

To deliver real-time deal pricing and library data, SteamValue communicates with the following public endpoints:

  • Steam Web API & Store API: Used to fetch public game details, prices, and library information.
  • CheapShark API: Used for game price comparison and search data.
  • Backend Proxy: Secure server proxy used to interface AI recommendation endpoints without exposing API keys.

4. Data Storage & Control

All stored profiles and settings are maintained in your browser's local storage. You have full control over your data and can clear or remove saved profiles at any time via Settings > Accounts within the extension.

5. Contact & Updates

If you have any questions regarding this Privacy Policy, you can reach out via GitHub or the extension support page.
